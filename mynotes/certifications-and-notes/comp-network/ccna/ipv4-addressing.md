# IPv4 Addressing

* **IPv4 Addressing Configuration**

`interface g0/0` : Acessar a interface especifica conetada no router ou switch

`ip address 10.255.255.254 255.0.0.0` : Configurar o endereço lógico (IP) e a máscara

`no shutdown` : Usamos este comando para habilitar a interface

`do show ip interface brief` : Mostrar o status da interface&#x20;

`show interfaces` : Mostra informações sobre as interfaces

`description ## to SW1 ##`

`show interface description` : Mostrar descrição das interfaces
