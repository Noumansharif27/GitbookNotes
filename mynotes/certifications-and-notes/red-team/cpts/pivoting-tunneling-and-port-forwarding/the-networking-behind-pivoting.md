# The Networking Behind Pivoting

* Comando baseado em Linux que exibe todas as configurações de rede atuais de um sistema.

```
ifconfig
```

* Comando baseado no Windows que exibe todas as configurações de rede do sistema.

```
ipconfig 
```

* Comando usado para exibir a tabela de roteamento para todos os protocolos baseados em IPv4.

```
netstat -r
```
