# Tmux

* Iniciar tmux

```sh
tmux
```

* tmux: prefixo padrão

```sh
ctrl+b
```

* tmux: nova janela

```sh
prefix c
```

* tmux: alternar para janela ( `1`)

```sh
prefix 1
```

* tmux: dividir painel verticalmente

```sh
prefix shift+%
```

* tmux: dividir painel horizontalmente

```sh
prefix shift+"
```

* tmux: alternar para o painel direito

```sh
prefix ->
```
