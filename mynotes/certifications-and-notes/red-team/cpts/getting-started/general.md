# General

* Conectar à VPN

```sh
sudo openvpn user.ovpn	
```

* Mostrar nosso endereço IP

```sh
ifconfig/ip a
```

* Mostrar redes acessíveis via VPN

```sh
netstat -rn
```

* SSH para um servidor remoto

```sh
ssh user@10.10.10.10
```

* FTP para um servidor remoto

```sh
ftp 10.129.42.253
```
