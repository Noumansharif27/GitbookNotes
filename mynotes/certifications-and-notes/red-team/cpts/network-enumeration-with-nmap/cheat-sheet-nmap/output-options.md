# Output Options

| **Opção Nmap** | **Descrição**                                                                            |
| -------------- | ---------------------------------------------------------------------------------------- |
| `-oA filename` | Armazena os resultados em todos os formatos disponíveis, começando pelo nome "filename". |
| `-oN filename` | Armazena os resultados no formato normal com o nome "nome do arquivo".                   |
| `-oG filename` | Armazena os resultados no formato "grepable" com o nome "filename".                      |
| `-oX filename` | Armazena os resultados no formato XML com o nome "filename".                             |
