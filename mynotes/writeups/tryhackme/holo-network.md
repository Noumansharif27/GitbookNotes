# HOLO - Network

Holo é um laboratório de ataque de Active Directory (AD) e aplicativos da Web que visa ensinar os principais vetores de ataque da Web e técnicas de ataque de AD mais avançadas.

**Classificação** : Hard

**Criador** : [tryhackme](https://tryhackme.com/p/tryhackme)

Neste laboratório, aprenderemos a explorar os seguintes tópicos:

* Noções básicas de .NET
* Exploração de aplicativos da web
* Evasão AV
* Lista de permissões e escapes de contêiner
* Pivoting
* Operando com uma estrutura C2 (Comando e Controle)
* Pós-exploração
* Consciência situacional
* Ataques ao Active Directory

Esta rede simula um teste de penetração externo em uma rede corporativa "Hololive" com uma kill chain pretendida.
